# Library Management System

Workshop 1 - Computer Programming III - UPC

## Author

Diego Armando Mestre Gomez

## Description

Console-based Java application for managing customers, books, and library loans. Data is stored in memory using ArrayList.

## How to Run

1. Open the project in NetBeans.
2. Compile the project using Maven.
3. Run `Main.java`.

## Features

- Customer CRUD
- Book CRUD
- Loan and return management
- Main menu to access all functionalities
